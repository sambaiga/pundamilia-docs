milia.data.profiles#

Daily profiles and day tensors built from a meter pivot.

These replace the per-notebook copies of “hour-of-day mean, then peak normalise” and of season_tensor.

milia.data.profiles.shape(pivot, dates=None, how='peak')#

Normalised mean daily profile of each meter, peak-normalised by default.

The representation most of the clustering chapters use: when in the day a meter consumes, with its size removed.

Parameters:

  • pivot (DataFrame) – Meter readings.

  • dates (DatetimeIndex | None) – Restrict to these days; all days when omitted.

  • how (Literal['peak', 'energy', 'zscore', 'minmax']) – Normalisation, see normalize().

Return type:

ndarray

Returns:

Array of shape (meters, steps); with how="peak" each row peaks at 1.

Examples

>>> import pandas as pd, numpy as np
>>> index = pd.date_range("2024-01-01", periods=48, freq="h")
>>> pivot = pd.DataFrame({"a": np.tile(np.arange(24.0), 2)}, index=index)
>>> float(shape(pivot).max())
1.0

milia.data.profiles.medoids(values, groups)#

The row of each group with the smallest total Euclidean distance to the others of its group.

The medoid summarises a group by one of its own members, so the summary keeps the shape and the peak of a real household that a mean smooths away. The mean minimises the sum of squared distances and the medoid the sum of distances, which makes it less sensitive to outliers.

Parameters:

  • values (ndarray) – Array of shape (rows, ...); every row is flattened for the distance.

  • groups (ndarray) – Group of each row, as a vector of length rows.

Return type:

dict[object, int]

Returns:

A dictionary from each group, in sorted order, to the index of its medoid among all rows.

Examples

>>> rows = np.array([[0.0], [1.0], [1.2], [10.0]])
>>> medoids(rows, np.array([0, 0, 0, 1]))
{0: 1, 1: 3}
milia.data.profiles.diversity(values, sizes, draws=100, random_state=0)#

Peak demand per household of a group of n households, as a share of the mean individual peak.

The demands of households do not peak at the same time, so the peak of the sum of n of them is less than n times the mean peak of one. The ratio of the first to the second, the coincidence factor, falls from one for a single household towards the ratio of the peak of the mean profile to the mean peak as n grows. It is the quantity that a representative profile built from a mean omits.

Parameters:

  • values (ndarray) – Array of shape (households, steps), or (households, days, steps), in kW.

  • sizes (Sequence[int]) – Numbers of households n to draw.

  • draws (int) – Random groups of each size.

  • random_state (int) – Seed of the draws.

Return type:

DataFrame

Returns:

A frame with one row per size and the columns size, mean (coincidence factor averaged over the draws), low and high (5th and 95th percentiles).

Examples

>>> flat = np.array([[1.0, 0.0], [0.0, 1.0]])
>>> diversity(flat, [1, 2], draws=5)["mean"].round(2).tolist()
[1.0, 0.5]
