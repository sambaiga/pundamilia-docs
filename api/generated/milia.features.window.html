milia.features.window#

Per-window features for anomaly detection: shape, rolling statistics and spectrum.

Each row of the input is one window of readings, typically one meter-day. A detector run on raw readings alone misses the shape that separates a genuine anomaly from ordinary daily variation, so each window becomes its peak-normalised shape plus summary statistics and its strongest frequencies.

milia.features.window.spectrum(profile, n=2)#

The largest non-constant FFT magnitudes of one window, largest first.

Captures periodic structure a reading-by-reading comparison misses, such as a cycling appliance.

Parameters:

  • profile (ArrayLike) – Readings of one window.

  • n (int) – Number of magnitudes kept; zero-padded when the window is too short.

Return type:

ndarray

Returns:

Array of shape (n,).

Examples

>>> t = np.linspace(0, 2 * np.pi, 48, endpoint=False)
>>> spectrum(np.sin(t) + 0.1 * np.sin(4 * t), n=2).round(1)
array([24. ,  2.4])
