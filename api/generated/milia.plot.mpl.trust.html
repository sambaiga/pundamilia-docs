milia.plot.mpl.trust#

Trust figures drawn with matplotlib (see milia.plot.figures.trust).

milia.plot.mpl.trust.calibration(profile, metrics=('strength', 'stability', 'subsample'), title=None)#

Each trust metric against k, on the data and on the structureless null.

Parameters:

  • draw – Drawing backend; bound for you in milia.plot.lets and milia.plot.mpl.

  • profile (DataFrame) – Output of milia.cluster.stability.calibrated().

  • metrics (Sequence[str]) – Trust metrics drawn.

  • title (str | None) – Figure title.

Returns:

The figure – a lets-plot PlotSpec or a matplotlib Figure, depending on the backend.

Examples

>>> import numpy as np, pandas as pd
>>> from milia.plot.mpl import trust
>>> profile = pd.DataFrame({"k": [2, 3], "strength": [0.9, 0.8], "strengthnull": [0.6, 0.4]})
>>> len(trust.calibration(profile, metrics=("strength",)).axes)
1
