milia.cluster.fitting#

Refitting a clusterer at a chosen number of clusters.

Model-selection code sweeps k by cloning one clusterer and setting its cluster count. milia’s clusterers all call it n_clusters; scikit-learn’s Gaussian mixture calls it n_components, so both are recognised.

milia.cluster.fitting.bycorrelation(series, k=3, method='spectral', random_state=0)#

Cluster the rows of a record by the correlation between them.

The correlation of two series ignores their level and scale and keeps their co-movement, so rows driven by a common source fall together. "spectral" treats (1 + correlation) / 2 as an affinity; "kmeans" clusters the rows of the correlation matrix.

Parameters:

  • series (ndarray) – Array of shape (rows, steps).

  • k (int) – Number of clusters.

  • method (str) – "spectral" or "kmeans".

  • random_state (int) – Seed.

Return type:

ndarray

Returns:

Cluster label of every row.

Raises:

ValueError – If method is neither "spectral" nor "kmeans".

Examples

>>> rng = np.random.default_rng(0)
>>> drivers = rng.normal(size=(2, 200))
>>> rows = np.vstack(
...     [drivers[0] + 0.1 * rng.normal(size=(4, 200)), drivers[1] + 0.1 * rng.normal(size=(4, 200))]
... )
>>> labels = bycorrelation(rows, k=2)
>>> len(set(labels[:4])), len(set(labels[4:])), bool(labels[0] != labels[4])
(1, 1, True)
