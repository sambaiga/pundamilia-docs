milia.core.registry#

Registry of detectors and clusterers.

A model registers by living in its kind’s models package, one module per model: milia/anomaly/models/iforest.py for the detector "iforest", milia/cluster/models/kmeans.py for the clusterer "kmeans". The module defines exactly one estimator (a subclass of the kind’s base class) and one config (a subclass of BaseModelConfig); the registry finds both by subclass, so no decorator or naming rule is needed.

Modules are imported lazily, so asking for one model never imports another model’s optional dependency.

milia.core.registry.get(kind, name)#

Look up a model’s estimator and config classes.

The model’s module is imported on first use and the pair cached.

Parameters:

  • kind (Literal['detector', 'clusterer']) – "detector" or "clusterer".

  • name (str) – Registry name, e.g. "iforest".

Return type:

tuple[type, type[BaseModelConfig]]

Returns:

(estimator class, config class).

Raises:

  • MissingExtraError – If the model needs an extra that is not installed.

  • ConfigurationError – If no such model exists.

Examples

>>> estimator, config = get("clusterer", "kmeans")
>>> estimator.__name__, config.__name__
('KMeans', 'KMeansConfig')
