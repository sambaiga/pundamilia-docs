milia.plot.mpl.draw#

Matplotlib primitives behind every figure (same signatures as milia.plot.lets.draw).

Figures follow the house style of milia.plot.style; call milia.plot.style.configure() once beforehand.

milia.plot.mpl.draw.grid(frame, facet, fraction=0.48, aspect=0.618, minimum=0.0)#

A figure with one axes per facet value, or a single axes.

Parameters:

  • frame (DataFrame) – Data.

  • facet (str | None) – Column whose values become panels, sorted; None for one axes.

  • fraction (float) – Share of the text width a single panel occupies.

  • aspect (float) – Height-to-width ratio of a panel.

  • minimum (float) – Smallest height of a row of panels, in inches.

Return type:

tuple[Figure, list[Axes], list]

Returns:

(figure, axes, keys) – the figure, one axes per panel and each panel’s facet value.

Examples

>>> import pandas as pd
>>> figure, axes, keys = grid(pd.DataFrame({"f": ["b", "a"]}), "f")
>>> keys
['a', 'b']

milia.plot.mpl.draw.groups(frame, x, y, group, highlight=None, markers=True, numbers=True, outline=True, title=None, xlabel=None, ylabel=None)#

Points of many groups, each outlined, numbered and given its own marker.

Colour alone cannot identify many groups, so each group has a marker shape, a pale outline (the convex hull of its points) and its name at its median. Neighbouring groups take the most different colours of the palette, and one group can be drawn in the highlight colour.

Matplotlib primitive behind milia.plot.figures.clusters.scatter().

Parameters:

  • frame (DataFrame) – Data.

  • x (str) – x column.

  • y (str) – y column.

  • group (str) – Column naming the group of each point.

  • highlight (str | None) – Name of the group drawn in the highlight colour.

  • markers (bool) – Give each group its own marker shape.

  • numbers (bool) – Write the name of each group at its median.

  • outline (bool) – Draw the convex hull of each group in a pale tint.

  • title (str | None) – Figure title.

  • xlabel (str | None) – x-axis label.

  • ylabel (str | None) – y-axis label.

Return type:

Figure

Returns:

A matplotlib Figure.

Examples

>>> import pandas as pd
>>> data = pd.DataFrame({"x": [0, 1, 0, 5, 6, 5], "y": [0, 0, 1, 5, 5, 6], "g": ["1"] * 3 + ["2"] * 3})
>>> type(groups(data, "x", "y", "g")).__name__
'Figure'
