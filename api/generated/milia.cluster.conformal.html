milia.cluster.conformal#

Split-conformal prediction sets for cluster membership (Lei, Rinaldo and Wasserman, 2015).

Instead of forcing each meter into one cluster, it gets the set of every cluster whose centroid lies within a calibrated distance. A meter with a set of two or more sits between archetypes; one with an empty set fits none.

milia.cluster.conformal.sets(X, estimator, alpha=0.1, test=0.3, random_state=0)#

Split-conformal cluster prediction sets (Lei, Rinaldo and Wasserman, 2015).

The clusterer is fitted on a training split; tau is the conformal quantile of the held-out rows’ nearest-centroid distances, so a new exchangeable row’s nearest cluster is in its set with probability at least 1 - alpha.

Parameters:

  • X (ArrayLike) – Data.

  • estimator (BaseEstimator) – A centroid clusterer already set to its k.

  • alpha (float) – Miscoverage level.

  • test (float) – Share of rows held out for calibration.

  • random_state (int) – Split seed.

Return type:

ConformalSets

Returns:

The calibrated ConformalSets.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> centres = np.repeat(np.array([[0.0, 0.0], [6.0, 6.0], [0.0, 6.0]]), 20, axis=0)
>>> X, truth = centres + rng.normal(scale=0.5, size=(60, 2)), np.repeat([0, 1, 2], 20)
>>> from milia import make
>>> rule = sets(X, make("clusterer", "kmeans", n_clusters=3), alpha=0.1)
>>> rule.centroids.shape, len(rule.predict(X[:2]))
((3, 2), 2)
