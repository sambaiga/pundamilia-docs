milia.benchmark.provenance.sha256(path)#

SHA-256 digest of a file, so an output records exactly which inputs it came from.

Parameters:

path (Path) – File to hash.

Return type:

str

Returns:

The hexadecimal digest.

Examples

>>> import tempfile
>>> from pathlib import Path
>>> folder = Path(tempfile.mkdtemp())
>>> (folder / "x.txt").write_text("a")
1
>>> sha256(folder / "x.txt")[:12]
'ca978112ca1b'

milia.benchmark.provenance.record(settings, inputs=None, packages=('pundamilia', 'scikit-learn', 'numpy', 'pandas', 'twiga'))#

The provenance record of a run: creation time, package versions, settings and input hashes.

Parameters:

  • settings (Mapping[str, Any]) – JSON-serialisable run settings.

  • inputs (Mapping[str, Path] | None) – Named input files; each is recorded by path and SHA-256.

  • packages (Sequence[str]) – Distributions whose versions are recorded.

Return type:

dict[str, Any]

Returns:

The record as a dictionary.

Examples

>>> sorted(record({"seed": 1}))
['created', 'inputs', 'packages', 'settings']

milia.benchmark.provenance.read(path)#

The provenance record of an output.

Parameters:

path (Path) – The output file.

Return type:

dict[str, Any]

Returns:

The record, or an empty dictionary when the output has none.

Examples

>>> import tempfile
>>> from pathlib import Path
>>> folder = Path(tempfile.mkdtemp())
>>> _ = write(folder / "scores.parquet", {"seed": 1})
>>> read(folder / "scores.parquet")["settings"], read(folder / "missing")
({'seed': 1}, {})
