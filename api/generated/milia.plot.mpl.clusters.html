milia.plot.mpl.clusters.scatter(embedding, labels, title=None, xlabel='dimension 1', ylabel='dimension 2', markers=False, numbers=False, outline=False, highlight=None)#

Two-dimensional embedding coloured by cluster.

Project first with milia.represent.reduce.project(). With many clusters, colour alone cannot identify them: markers gives each cluster its own marker shape, numbers writes its number (from 1, the label plus one) at its median, outline draws its convex hull in a pale tint, and highlight draws one cluster, such as a minority that stands apart, in the highlight colour of the style. Neighbouring clusters then take the most different colours of the palette.

Parameters:

  • draw – Drawing backend; bound for you in milia.plot.lets and milia.plot.mpl.

  • embedding (ArrayLike) – Coordinates, shape (n, 2) (further columns are ignored).

  • labels (ArrayLike) – Cluster label of each row.

  • title (str | None) – Figure title.

  • xlabel (str) – x-axis label.

  • ylabel (str) – y-axis label.

  • markers (bool) – Give each cluster its own marker shape.

  • numbers (bool) – Write the number of each cluster at its median.

  • outline (bool) – Draw the convex hull of each cluster.

  • highlight (int | None) – Label of the cluster drawn in the highlight colour.

Returns:

The figure – a lets-plot PlotSpec or a matplotlib Figure, depending on the backend.

Examples

>>> import numpy as np, pandas as pd
>>> from milia.plot.mpl import clusters
>>> figure = clusters.scatter(np.random.default_rng(0).normal(size=(10, 2)), [0, 1] * 5)
>>> type(figure).__name__
'Figure'
>>> figure = clusters.scatter(
...     np.random.default_rng(0).normal(size=(12, 2)), [0, 1, 2] * 4, markers=True, numbers=True, outline=True
... )
>>> type(figure).__name__
'Figure'
milia.plot.mpl.clusters.validity(scores, metrics=None, normalize=False, title=None)#

Validity metrics against k.

One panel per metric, or with normalize all metrics on one axis, each min-max scaled and oriented so higher is better.

Parameters:

  • draw – Drawing backend; bound for you in milia.plot.lets and milia.plot.mpl.

  • scores (DataFrame) – Sweep table from milia.cluster.validation.sweep().

  • metrics (Sequence[str] | None) – Metrics drawn; every metric present by default.

  • normalize (bool) – Share one normalised axis.

  • title (str | None) – Figure title.

Returns:

The figure – a lets-plot PlotSpec or a matplotlib Figure, depending on the backend.

Examples

>>> import numpy as np, pandas as pd
>>> from milia.plot.mpl import clusters
>>> scores = pd.DataFrame({"k": [2, 3, 4], "silhouette": [0.5, 0.8, 0.6], "davies": [0.7, 0.4, 0.6]})
>>> len(clusters.validity(scores).axes)
2
