milia.plot.style#

Matplotlib house style for publication figures.

SciencePlots’ science style through twiga’s configure_matlib_style, with these overrides: serif type (Times New Roman) set through LaTeX, 10 pt labels, thin rules, no grid, no legend frame and the project palette. Figures are authored one panel at a time at the size they will occupy (panel()) and saved as PDF, so LaTeX composes the sub-figures.

LaTeX is on by default; call configure(latex=False) on a machine without TeX. With LaTeX on, any text from data must go through texsafe().

milia.plot.style.panel(fraction=0.48, aspect=0.618)#

figsize for a panel occupying a share of the text width.

Authoring each panel at the size it will finally occupy keeps type the same size across a composed figure; scaling panels in LaTeX does not.

Parameters:

  • fraction (float) – Share of the text width: 0.48 for two panels side by side, 0.31 for three, 1.0 for a full-width panel.

  • aspect (float) – Height as a multiple of width.

Return type:

tuple[float, float]

Returns:

(width, height) in inches.

Examples

>>> [round(v, 3) for v in panel(0.5, aspect=1.0)]
[3.15, 3.15]
milia.plot.style.configure(latex=True, size=12.0)#

Apply the house style globally.

Calls twiga’s configure_matlib_style (SciencePlots’ science style and the LaTeX toolchain) and layers RC on top.

Parameters:

  • latex (bool) – Typeset text through LaTeX; set False on a machine without TeX.

  • size (float) – Base font size passed to twiga.

Return type:

None

Examples

>>> configure(latex=False)
>>> import matplotlib as mpl
>>> mpl.rcParams["font.family"]
['serif']

milia.plot.style.sketch(latex=True, scale=1.2, length=130, randomness=3, **overrides)#

The house style with hand-drawn paths, for illustrations rather than results.

Only the paths wobble; text stays in the house serif.

Parameters:

  • latex (bool) – Typeset text through LaTeX.

  • scale (float) – Wobble amplitude, in points.

  • length (float) – Wobble wavelength, in points.

  • randomness (float) – Jitter of the wavelength, in percent.

  • **overrides (Any) – Extra rc settings.

Yields:

Nothing; the style is active inside the block.

Examples

>>> import matplotlib as mpl
>>> with sketch(latex=False):
...     mpl.rcParams["path.sketch"]
(1.2, 130.0, 3.0)

milia.plot.style.pad(*arrays, frac=0.04, floor=1e-09)#

Axis limits around every array, padded by a share of the range.

A deliberate margin, so a point at the extreme does not sit on the spine.

Parameters:

  • *arrays (Any) – Every array the axis will show.

  • frac (float) – Padding as a share of the range.

  • floor (float) – Smallest padding.

Return type:

tuple[float, float] | None

Returns:

(low, high), or None when there is nothing finite to pad.

Examples

>>> pad([0.0, 1.0])
(-0.04, 1.04)
>>> pad([]) is None
True

Legend centred below the axes; place() moves it just under the x-axis label after layout.
