milia.recommend.ranking#

Ranking cases, groups and models, with uncertainty on the ranks.

weights() is the single diversity weighting used everywhere a ranking combines several metrics (cluster-count selection and model comparison alike): a metric that mostly repeats others gets less weight.

milia.recommend.ranking.weights(scores)#

Diversity weights of metric columns from their mean absolute Spearman correlation.

Each metric’s weight is one minus its mean absolute correlation with the others, floored at 0.05 and normalised to sum to one, so a metric that mostly repeats others counts less.

Parameters:

scores (DataFrame) – One column per metric, oriented higher-is-better, one row per candidate.

Return type:

ndarray

Returns:

One weight per column.

Examples

>>> import pandas as pd
>>> scores = pd.DataFrame({"a": [1, 2, 3], "b": [1, 2, 3], "c": [3, 1, 2]})
>>> weights(scores).round(2).tolist()
[0.3, 0.3, 0.4]

milia.recommend.ranking.interval(frame, score, ascending=False, bootstrap=200, random_state=0)#

rank() plus a bootstrap interval on each rank.

The cases are resampled with replacement and re-ranked; the 5th and 95th percentiles of each case’s positions give lower and upper. Wide intervals mean the order among those cases is not settled.

Parameters:

  • frame (DataFrame) – One row per case.

  • score (str) – Column ranked on.

  • ascending (bool) – Rank the lowest score first.

  • bootstrap (int) – Resamples.

  • random_state (int) – Seed.

Return type:

DataFrame

Returns:

The ranked frame with lower and upper.

Examples

>>> import pandas as pd
>>> ranked = interval(pd.DataFrame({"s": [1.0, 2.0, 3.0]}), "s", bootstrap=50)
>>> bool((ranked["lower"] <= ranked["rank"]).all())
True

milia.recommend.ranking.models(scores, lower=None)#

Diversity-weighted multi-metric ranking of models.

Metrics named in lower are negated so higher is better throughout; each metric is ranked across models and combined three ways: mean rank, Borda count, and Borda weighted by weights().

Parameters:

  • scores (DataFrame) – One row per model, one column per metric.

  • lower (Iterable[str] | None) – Lower-is-better metric names; LOWER by default.

Return type:

DataFrame

Returns:

scores with mean, borda and weighted, best first; the weights are in attrs["weights"].

Examples

>>> import pandas as pd
>>> scores = pd.DataFrame({"mae": [1.0, 2.0], "corr": [0.9, 0.5]}, index=["knn", "mean"])
>>> models(scores).index.tolist()
['knn', 'mean']
