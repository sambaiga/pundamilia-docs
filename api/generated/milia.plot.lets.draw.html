milia.plot.lets.draw.finish(plot, title, xlabel, ylabel, hlines=(), vlines=())#

Add reference lines, labels and the theme to a plot.

Parameters:

  • plot (Any) – A lets-plot PlotSpec.

  • title (str | None) – Figure title.

  • xlabel (str | None) – x-axis label.

  • ylabel (str | None) – y-axis label.

  • hlines – y values of dashed reference lines.

  • vlines – x values of dashed reference lines.

Return type:

Any

Returns:

The finished PlotSpec.

Examples

>>> import pandas as pd
>>> from lets_plot import aes, geom_point, ggplot
>>> plot = finish(
...     ggplot(pd.DataFrame({"x": [1]}), aes(x="x", y="x")) + geom_point(), "t", "x", "y", hlines=(1,)
... )
>>> len(plot.as_dict()["layers"])
2

milia.plot.lets.draw.groups(frame, x, y, group, highlight=None, markers=True, numbers=True, outline=True, title=None, xlabel=None, ylabel=None)#

Points of many groups, each outlined, numbered and given its own marker.

Colour alone cannot identify many groups, so each group has a marker shape, a pale outline (the convex hull of its points) and its name at its median. Neighbouring groups take the most different colours of the palette, and one group can be drawn in the highlight colour.

Lets-plot primitive behind milia.plot.figures.clusters.scatter().

Parameters:

  • frame (DataFrame) – Data.

  • x (str) – x column.

  • y (str) – y column.

  • group (str) – Column naming the group of each point.

  • highlight (str | None) – Name of the group drawn in the highlight colour.

  • markers (bool) – Give each group its own marker shape.

  • numbers (bool) – Write the name of each group at its median.

  • outline (bool) – Draw the convex hull of each group in a pale tint.

  • title (str | None) – Figure title.

  • xlabel (str | None) – x-axis label.

  • ylabel (str | None) – y-axis label.

Return type:

Any

Returns:

A lets-plot PlotSpec.

Examples

>>> import pandas as pd
>>> data = pd.DataFrame({"x": [0, 1, 0, 5, 6, 5], "y": [0, 0, 1, 5, 5, 6], "g": ["1"] * 3 + ["2"] * 3})
>>> bool(groups(data, "x", "y", "g").as_dict()["layers"])
True
