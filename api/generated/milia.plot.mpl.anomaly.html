milia.plot.mpl.anomaly#

Anomaly figures drawn with matplotlib (see milia.plot.figures.anomaly).

milia.plot.mpl.anomaly.band(trace, low=0.94, high=1.1, x='step', y='vmag_pu', group='load_name', title=None)#

Per-entity traces against a compliance band, entities leaving it highlighted.

Parameters:

  • draw – Drawing backend; bound for you in milia.plot.lets and milia.plot.mpl.

  • trace (DataFrame) – Long frame with one row per entity and step.

  • low (float) – Lower bound of the band.

  • high (float) – Upper bound of the band.

  • x (str) – Step column.

  • y (str) – Value column.

  • group (str) – Entity column.

  • title (str | None) – Figure title.

Returns:

The figure – a lets-plot PlotSpec or a matplotlib Figure, depending on the backend.

Examples

>>> import numpy as np, pandas as pd
>>> from milia.plot.mpl import anomaly
>>> trace = pd.DataFrame({"step": [0, 1, 0, 1], "vmag_pu": [1.0, 1.0, 1.0, 1.12], "load_name": list("aabb")})
>>> type(anomaly.band(trace)).__name__
'Figure'
