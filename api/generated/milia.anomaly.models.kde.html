class milia.anomaly.models.kde.KDE(bandwidth=1.0, kernel='gaussian', contamination=0.1)#

Bases: BaseDetector

Density detector: negative log-density under a kernel density estimate.

Parameters:

  • bandwidth (float | str) – Kernel bandwidth, or "scott"/"silverman".

  • kernel (str) – Kernel name, as in sklearn.neighbors.KernelDensity.

  • contamination (float) – Expected share of outliers, used for the default threshold.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> train, cal = rng.normal(size=(200, 2)), rng.normal(size=(100, 2))
>>> model = KDE().fit(train).calibrate(cal, alpha=0.1)
>>> model.flag(np.array([[0.0, 0.0], [8.0, 8.0]])).tolist()
[False, True]
