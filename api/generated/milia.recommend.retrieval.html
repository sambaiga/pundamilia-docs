milia.recommend.retrieval#

Content-based retrieval: predict an entity’s outcome from its nearest labelled neighbours.

Two split-conformal calibrations on held-out labelled rows say how far to believe a retrieval.

  • The trust radius bounds novelty. A query’s score is the distance to its nearest labelled neighbour, and the radius \(\hat q\) is the conformal quantile of the held-out scores; a query farther than \(\hat q\) has no trustworthy precedent, e.g. a customer from another population or one changed by new DER.

  • The error interval bounds accuracy. With the held-out outcomes, the residual \(|y - \hat y|\) is calibrated into an interval \(\hat y \pm \varepsilon\); in its locally adaptive form the residual is divided by the spread of the neighbours’ outcomes \(\hat\sigma_k\), giving \(\hat y \pm \varepsilon\, \hat\sigma_k\), wider where the neighbours disagree [Romano et al., 2019].

Either calibration can be made per group, such as a network or a regime (Mondrian conformal prediction, Vovk et al., 2005), so that its guarantee holds within each group rather than only on average over them.

calibrate(X, alpha=0.1, y=None, groups=None, adaptive=False)#

Calibrate the trust radius and, given outcomes, the error interval on held-out labelled rows.

The trust radius tau_ is the split-conformal quantile of the held-out rows’ distances to their nearest labelled neighbour, so a new exchangeable row lies within it with probability at least 1 - alpha. With y, the error quantile epsilon_ is the same quantile of the residuals |y - predict(X)|, divided by spread() when adaptive, and interval() then covers a new exchangeable outcome with probability at least 1 - alpha. With groups, both are also calibrated within each group.

Parameters:

  • X (ArrayLike) – Held-out labelled features, not used in fit.

  • alpha (float) – Miscoverage level.

  • y (ArrayLike | None) – Held-out outcomes; the error interval is calibrated only when given.

  • groups (ArrayLike | None) – Group of each held-out row, such as its network; calibrates per group when given.

  • adaptive (bool) – Scale the residuals by the neighbours’ spread.

Return type:

KNNRetriever

Returns:

The retriever, calibrated.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> X = rng.normal(size=(80, 2))
>>> y = 2 * X[:, 0]
>>> model = KNNRetriever().fit(X[:60], y[:60]).calibrate(X[60:])
>>> bool(np.isfinite(model.tau_)), model.trusted([[50.0, 50.0]]).tolist()
(True, [False])

pvalue(X)#

Conformal p-value of each row’s distance to its nearest labelled neighbour.

A row is trusted at level alpha when its p-value exceeds alpha; a small p-value marks a query that lies farther from every labelled row than all but a few held-out rows did.

Parameters:

X (ArrayLike) – Query features.

Return type:

ndarray

Returns:

One p-value per row, in (0, 1].

Raises:

ValueError – If the retriever was not calibrated.

Examples

>>> rng = np.random.default_rng(0)
>>> X = rng.normal(size=(100, 2))
>>> model = KNNRetriever().fit(X[:60], X[:60, 0]).calibrate(X[60:])

set_score_request(*, sample_weight='$UNCHANGED$')#

Configure whether metadata should be requested to be passed to the score method.

Note that this method is only relevant when this estimator is used as a sub-estimator within a meta-estimator and metadata routing is enabled with enable_metadata_routing=True (see sklearn.set_config()). Please check the User Guide on how the routing mechanism works.

The options for each parameter are:

  • True: metadata is requested, and passed to score if provided. The request is ignored if metadata is not provided.

  • False: metadata is not requested and the meta-estimator will not pass it to score.

  • None: metadata is not requested, and the meta-estimator will raise an error if the user provides it.

  • str: metadata should be passed to the meta-estimator with this given alias instead of the original name.

The default (sklearn.utils.metadata_routing.UNCHANGED) retains the existing request. This allows you to change the request for some parameters and not others.

Added in version 1.3.
