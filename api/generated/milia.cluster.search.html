milia.cluster.search#

Multi-objective search over whole clustering pipelines (Optuna, NSGA-II).

Each trial picks a feature set, a scaler, a reducer (with its own hyperparameters), a clusterer and k, and is scored on three objectives, all maximised: separation, cluster balance, and a cheap prediction-strength proxy for stability. With gated=True the search is single-objective: separation, with trials whose weaker trust signal falls below threshold discarded.

The Pareto front is only a shortlist: audit the chosen trial with the full resampling checks (audit()) before trusting it.

milia.cluster.search.audit(params, sets, choices=None, ks=range(2, 11), splits=10, bootstrap=100)#

Rebuild one trial’s input and run the full validity and resampling sweep over k.

The search’s stability proxy is cheap by design; this is the careful check to run on the trial you intend to use.

Parameters:

  • params (Mapping[str, Any]) – The trial’s parameters.

  • sets (Mapping[str, DataFrame]) – Named feature sets, from featuresets().

  • choices (Mapping[str, BaseEstimator] | None) – Named clusterers; clusterers() with extended=True by default.

  • ks (Sequence[int]) – Candidate numbers of clusters.

  • splits (int) – Prediction-strength splits.

  • bootstrap (int) – Bootstrap resamples.

Return type:

tuple[ndarray, DataFrame, int]

Returns:

(X, scores, k) – the rebuilt input, the sweep table, and the k the trust gate recommends.

Examples

>>> from milia.data import synthetic
>>> sets = featuresets(synthetic.generate(meters=12, days=21, steps=24).pivot)
>>> params = {
...     "feature": "shape",
...     "scaler": "standard",
...     "reducer": "pca",
...     "pcacomponents": 2,
...     "clusterer": "kmeans",
...     "k": 3,
... }
>>> X, scores, k = audit(params, sets, ks=range(2, 4), splits=2, bootstrap=2)
>>> X.shape, k in (2, 3)
((12, 2), True)

milia.cluster.search.objective(sets, choices, scalers=('standard', 'minmax', 'robust', 'quantile', 'power'), separation='silhouette', dbcv=False, embedding=False, gated=False, threshold=0.7, splits=3, raw=False, kmin=3, kmax=12)#

The Optuna objective for search().

Parameters:

  • sets (Mapping[str, DataFrame]) – Named feature sets.

  • choices (Mapping[str, BaseEstimator]) – Named clusterers.

  • scalers (Sequence[str]) – Scaler names to choose between.

  • separation (Literal['silhouette', 'densitysilhouette']) – Separation metric; "densitysilhouette" reproduces ark’s searches.

  • dbcv (bool) – Use the lower of separation and DBCV (kNN core distance) as separation.

  • embedding (bool) – Search the output dimension of t-SNE, UMAP and PaCMAP too.

  • gated (bool) – Single-objective search with a trust floor.

  • threshold (float) – Trust floor for gated.

  • splits (int) – Prediction-strength splits of the stability proxy.

  • raw (bool) – Allow no reduction.

  • kmin (int) – Smallest k.

  • kmax (int) – Largest k.

Returns:

A function of an Optuna trial returning separation, balance and the stability proxy (or separation alone when gated). Invalid configurations are pruned.

Examples

>>> from milia.data import synthetic
>>> sets = featuresets(synthetic.generate(meters=12, days=21, steps=24).pivot)
>>> trial = optuna.trial.FixedTrial(
...     {
...         "feature": "shape",
...         "scaler": "standard",
...         "reducer": "pca",
...         "pcacomponents": 2,
...         "clusterer": "kmeans",
...         "k": 3,
...     }
... )
>>> len(objective(sets, clusterers())(trial))
3

milia.cluster.search.recheck(candidates, sets, choices=None, **settings)#

Null-calibrated trust of several trials at their own k.

Raw stability favours small k; the excess over a structureless reference does not, so this is the fairer comparison between Pareto candidates (see calibrated()).

Parameters:

  • candidates (Sequence[Mapping[str, Any]]) – Trial parameters, one mapping per candidate.

  • sets (Mapping[str, DataFrame]) – Named feature sets.

  • choices (Mapping[str, BaseEstimator] | None) – Named clusterers.

  • **settings (Any) – Passed to calibrated().

Return type:

DataFrame

Returns:

One row per candidate – its pipeline, k and the calibrated metrics.

Examples

>>> from milia.data import synthetic
>>> sets = featuresets(synthetic.generate(meters=12, days=21, steps=24).pivot)
>>> params = {
...     "feature": "shape",
...     "scaler": "standard",
...     "reducer": "pca",
...     "pcacomponents": 2,
...     "clusterer": "kmeans",

milia.cluster.search.search(pivot, trials, name, storage, hemisphere='south', choices=None, normalized=False, population=60, random_state=0, every=20, **settings)#

Run, or resume, the pipeline search on a meter pivot.

The study is stored in storage/<name>.db and resumed when it exists, so only the missing trials run.

Parameters:

  • pivot (DataFrame) – Meter pivot.

  • trials (int) – Total trials wanted.

  • name (str) – Study name.

  • storage (Path) – Directory of the SQLite study.

  • hemisphere (Literal['north', 'south']) – Season convention for the seasonal feature set.

  • choices (Mapping[str, BaseEstimator] | None) – Named clusterers; clusterers() by default.

  • normalized (bool) – Daily-max normalise before the profile feature sets.

  • population (int) – NSGA-II population size.

  • random_state (int) – Sampler seed.

  • every (int | None) – Log progress every this many trials (None for silence).

  • **settings (Any) – Passed to objective().

Return type:

Study

Returns:

The study; study.trials_dataframe() gives the table.

Raises:

ValueError – If an existing study has a different number of objectives.

Examples

>>> import tempfile
>>> from pathlib import Path
>>> from milia.data import synthetic
>>> pivot = synthetic.generate(meters=20, days=14, steps=24).pivot
>>> study = search(pivot, trials=4, name="demo", storage=Path(tempfile.mkdtemp()), population=2, kmax=4)
>>> len(study.trials)
4
milia.cluster.search.suggest(trial, name, cap, embedding=False)#

A reducer with hyperparameters sampled from an Optuna trial.

PCA and kernel PCA always search their dimension; t-SNE, UMAP and PaCMAP stay at two components unless embedding is set.

Parameters:

  • trial (Trial) – The active Optuna trial.

  • name (str) – Reducer name from REDUCERS, or "none".

  • cap (int) – Largest dimension allowed, min(n_samples, n_features) of the input.

  • embedding (bool) – Also search the output dimension of t-SNE, UMAP and PaCMAP.

Return type:

object | None

Returns:

The unfitted reducer, or None for "none".

Raises:

ValueError – If the name is unknown.

Examples

>>> trial = optuna.trial.FixedTrial({"pcacomponents": 3})
>>> suggest(trial, "pca", cap=5).n_components
3
