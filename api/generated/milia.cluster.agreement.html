milia.cluster.agreement#

Agreement between clusterings: across algorithms, seeds, time windows and known groups.

The key protocol is the noise floor: drift between two time windows is only real if their agreement is lower than the agreement between two seeds of the same algorithm on the same data (seeds()).

milia.cluster.agreement.families(X, k, estimators=None)#

Labels of the same data from one clusterer per objective family.

Partition (k-means), probabilistic (GMM), hierarchy (agglomerative), graph (spectral) and density (DBSCAN, which ignores k and may label noise -1). High agreement across families means the structure does not depend on the algorithm’s assumptions.

Parameters:

  • X (ArrayLike) – Data.

  • k (int) – Number of clusters for the families that take one.

  • estimators (Mapping[str, BaseEstimator] | None) – Name to clusterer; one per family (FAMILIES) by default.

Return type:

dict[str, ndarray]

Returns:

Name to labels.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> centres = np.repeat(np.array([[0.0, 0.0], [6.0, 6.0], [0.0, 6.0]]), 20, axis=0)
>>> X, truth = centres + rng.normal(scale=0.5, size=(60, 2)), np.repeat([0, 1, 2], 20)
>>> out = families(X, 3)
>>> sorted(out), round(float(pairwise(out).loc["kmeans", "gmm"]), 2)
(['agglomerative', 'dbscan', 'gmm', 'kmeans', 'spectral'], 1.0)
milia.cluster.agreement.seeds(X, estimator, k, values=range(0, 5))#

Pairwise ARI between fits that differ only in random_state: the noise floor.

Drift between two time windows is only real if their agreement falls below this floor.

Parameters:

  • X (ArrayLike) – Data.

  • estimator (BaseEstimator) – Clusterer with a random_state hyperparameter.

  • k (int) – Number of clusters.

  • values (Sequence[int]) – Seeds compared.

Return type:

ndarray

Returns:

One ARI per pair of seeds.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> centres = np.repeat(np.array([[0.0, 0.0], [6.0, 6.0], [0.0, 6.0]]), 20, axis=0)
>>> X, truth = centres + rng.normal(scale=0.5, size=(60, 2)), np.repeat([0, 1, 2], 20)
>>> from milia import make

>>> seeds(X, kmeans, 3, values=range(3)).round(2).tolist()

milia.cluster.agreement.drift(periods, index, estimator, k)#

Track one entity across periods: distance to its own centroid and to the nearest other.

When the second falls below the first, the entity has moved to another cluster, e.g. after adopting an EV.

Parameters:

  • periods (Mapping[Hashable, ArrayLike]) – Period name to all entities’ features in that period.

  • index (int) – Row of the tracked entity.

  • estimator (BaseEstimator) – Clusterer.

  • k (int) – Number of clusters.

Return type:

DataFrame

Returns:

One row per period with cluster, own and other.

Examples

>>> import numpy as np
>>> rng = np.random.default_rng(0)
>>> centres = np.repeat(np.array([[0.0, 0.0], [6.0, 6.0], [0.0, 6.0]]), 20, axis=0)
>>> X, truth = centres + rng.normal(scale=0.5, size=(60, 2)), np.repeat([0, 1, 2], 20)
>>> from milia import make
>>> kmeans = make("clusterer", "kmeans", n_init=5)

milia.cluster.agreement.assign(similarity)#

Match each cluster to a distinct reference class by the largest total similarity.

A clustering names its groups arbitrarily. When a few members of known class are available, each cluster is compared with the mean of every known class and the one-to-one assignment with the largest summed similarity (the Hungarian method) gives the cluster its class. Undefined similarities count as the lowest, so a class that is absent never wins.

Parameters:

similarity (ArrayLike) – Array of shape (clusters, classes).

Return type:

ndarray

Returns:

For each cluster the index of its class, or -1 when there are more clusters than classes.

Examples

>>> assign([[0.1, 0.9], [0.8, 0.2]]).tolist()
[1, 0]
>>> assign([[0.9, 0.1], [0.8, 0.2], [0.1, 0.0]]).tolist()
[0, 1, -1]
