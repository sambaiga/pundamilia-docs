Cluster#

milia.cluster groups series that behave alike, decides how many groups the data supports, and reports how far to trust them.

from milia import available, make
from milia.data import profiles, synthetic

population = synthetic.generate(meters=60, days=90, steps=48)
shapes = profiles.shape(population.pivot)

Choose the number of groups#

validation.sweep scores every candidate number of groups by internal validity, and with resampling=True by prediction strength, the smallest-cluster bootstrap and subsample agreement. selection.recommend applies a strategy to the table. The trust strategy only accepts a number of groups that passes the resampling checks.

from milia.cluster import selection, validation

scores = validation.sweep(shapes, range(2, 8), resampling=True)
k = selection.recommend(scores, strategy="trust")
scores[["k", "silhouette", "davies", "strength", "stability"]].round(2)

Fit and check#

model = make("clusterer", "kmeans", n_clusters=k)
labels = model.fit_predict(shapes)
validation.internal(shapes, labels), validation.external(labels, population.labels)

({'silhouette': 0.9749082728449507,
  'calinski': 36096.83062214639,
  'davies': 0.03406303662333405,
  'balance': 0.9999999999999998},
 {'ari': 1.0, 'nmi': 1.0, 'purity': 1.0})

When the true grouping is known, as it is here, validation.external measures agreement with it. On real data there is no truth, which is why the resampling checks matter.

Combine clusterers#

Consensus clusters the same data with several clusterers, or with one clusterer over several seeds, and groups the series that are most often put together.

from milia.cluster.consensus import Consensus

consensus = Consensus(n_clusters=k).fit_predict(shapes)
[int((consensus == group).sum()) for group in range(k)]

[20, 20, 20]

Say when a series is ambiguous#

conformal.sets calibrates a distance threshold on held-out series, so that a new series gets a set of groups: one when it clearly belongs, several when it is between groups, none when it is far from all of them.

from milia.cluster import conformal

sets = conformal.sets(shapes, make("clusterer", "kmeans", n_clusters=k), alpha=0.1)
sets.tau, sets.alpha

(0.06547433293370267, 0.1)

Limits#

k-means assumes compact, similarly sized groups. The resampling checks tell you when a split is not stable, not whether the groups are useful for your decision. Read the clusters, not only the indices.
